# Changelog

## 0.2.0

First public release.

- Local web app for personas, user journeys, user flows and user stories stored as Markdown and JSON in a project's `docs/ux/` folder.
- Journey boards with drag and drop, persona comparison, keyboard movement, and CSV import and export.
- CLI commands `init`, `start`, `demo` and `export`, with a production runtime bound to 127.0.0.1.
- Stdio MCP server with document tools and an MCP App view of the same interface.
- Agent skill describing the planning file formats.
- Static landing page with an in-browser demo.
