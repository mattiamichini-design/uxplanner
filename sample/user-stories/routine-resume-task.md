# Resume the last task

> As a returning user, I want to resume my last task from the home page, so that I can continue without searching for it.

## Acceptance Criteria

| ID | Criterion | Priority |
| --- | --- | --- |
| EU1 | The home page lists the three most recent tasks. | Must |
| EU2 | Opening a recent task restores its last saved state. | Must |
| EU3 | Each save adds an entry to the task history. | Should |
