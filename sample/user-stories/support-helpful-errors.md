# Errors that suggest a next step

> As a user who hits a problem, I want each error to tell me what to do next, so that I can fix it without losing my work.

## Acceptance Criteria

| ID | Criterion | Priority |
| --- | --- | --- |
| SP1 | Every error message says what happened and what to do next. | Must |
| SP2 | When an article exists, the error links to it. | Should |
| SP3 | Work in progress is saved before the user leaves the page. | Must |
