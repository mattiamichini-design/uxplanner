## Distribution

GitHub is the only distribution channel for this application. Document cloning/building this repository and running its CLI directly with the consumer root. Do not publish application packages to public package registries or add registry-install examples to product copy. Package-manager commands remain valid for third-party development dependencies and local artifact verification.

## Git and CI

Run the checks in CONTRIBUTING.md locally before you push. Open pull requests as drafts while you iterate, push follow-up fixes together, and mark the pull request ready once: CI skips drafts, and each push to a ready pull request starts a full run.
